# Proyecto y documentos web

**FR-17 / CA-17.** Al seleccionar texto por primera vez en el panel lateral, definir o elegir un proyecto y agregar la página en una sola acción. Agregar nuevas páginas de forma explícita antes de etiquetar y retomar la selección al terminar. La URL identifica al documento dentro del proyecto. Los documentos, citas, categorías, notas y vínculos existentes conservan sus identificadores.

**FR-18 / CA-18.** Desde las opciones de la extensión, descargar el proyecto como ZIP con una carpeta del proyecto, un índice y un JSON por documento web. El JSON incluye las citas, los selectores, las notas y los datos de las categorías aplicadas. El índice conserva el catálogo completo y los vínculos. Los formatos de exportación e importación JSON existentes siguen disponibles.
